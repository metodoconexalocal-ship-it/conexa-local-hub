DC Tracker v1.0

📊 Como Instalar o Rastreamento

Guia para adicionar o DC Tracker na landing page do seu cliente e começar a rastrear a origem de cada lead em tempo real.

Passo 1 — Configurar o Supabase

1
Executar o schema no banco

Abra o arquivo schema.sql (nesta mesma pasta), copie todo o conteúdo e cole em:
Supabase → SQL Editor → New Query → Cole → Run

Isso cria as tabelas lead_sessions e lead_events com as políticas de segurança corretas.

2
Pegar as chaves do Supabase

No painel do Supabase: Settings → API

ChaveOnde usarOnde encontrar
anon (public)tracker.js na LP (seguro)Settings → API → anon public
service_roleDashboard DC Hub (privado)Settings → API → service_role
Project URLAmbosSettings → API → Project URL
⚠️ A service_role key NUNCA vai para o site público — só fica no DC Hub (painel interno).

Passo 2 — Instalar na Landing Page

3
Copie os dois arquivos para a pasta do site

Copie tracker.js para a raiz ou pasta /js/ da landing page.

4
Cole o código ANTES do </body>
<!-- DC Tracker — cole antes do </body> -->
<script>
  window.TRACKER_CONFIG = {
    supabaseUrl: 'https://SEU-PROJETO.supabase.co',
    supabaseKey: 'sua-anon-key-aqui',
    site: 'nome-do-cliente',   // ex: 'escola-futebol' ou 'clinica-dental'
    whatsappTrack: true,    // injeta origem na mensagem do WhatsApp
    autoTrackClicks: true,  // rastreia cliques automaticamente
    debug: false,           // true = mostra logs no console
  };
</script>
<script src="tracker.js"></script>

Passo 3 — Configurar os Anúncios com UTM

Para rastrear palavras-chave do Google Ads, adicione os parâmetros UTM na URL final dos anúncios:

# Google Ads (palavra-chave automática)
https://seusite.com.br?utm_source=google&utm_medium=cpc&utm_campaign=nome-campanha&utm_term={keyword}

# Google Meu Negócio (link do perfil)
https://seusite.com.br?utm_source=gmb

# Instagram (bio ou stories)
https://seusite.com.br?utm_source=instagram&utm_medium=social&utm_campaign=bio

# Facebook Ads
https://seusite.com.br?utm_source=facebook&utm_medium=cpc&utm_campaign=nome-campanha
💡 No Google Ads, use {keyword} (com chaves) — o Google substitui automaticamente pela palavra que o usuário buscou.

Passo 4 — Abrir o Dashboard

Abra o DC Hub e clique em 📊 Métricas de Leads na barra lateral.

Na primeira vez, você precisa informar a URL do projeto Supabase e a service_role key. Elas ficam salvas no navegador — não precisará repetir.

Uso Avançado — API Manual

Se quiser registrar eventos customizados no seu JavaScript:

// Rastrear evento customizado
DCTracker.trackEvent('video_play', { video: 'depoimento-joao' });

// Abrir WhatsApp com origem já na mensagem
DCTracker.openWhatsApp('5548999999999', 'Olá, quero saber mais!');

// Ver de onde veio o lead (para exibir em página de obrigado, etc.)
console.log(DCTracker.getOriginLabel());
// → "Google Ads · 🔍 escola futebol palhoça"
